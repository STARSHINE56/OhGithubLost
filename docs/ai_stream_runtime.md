# AI 流式与运行时后续实现（开发分支，未构建）

基于 66cb827，分支 improvement/ai-stream-runtime。保留之前即时消息、正式工作台
布局、上下文选择、会话标题；用户要求先不构建，不合 main，不触发 APK/Release。

## 已实现

- 三协议流式：OpenAI SSE delta、Anthropic block/delta/stop、Gemini streamGenerateContent。
- 沿用原协议请求转换与鉴权；完整聚合工具 arguments / thoughtSignature 后才执行。
- SSE UTF8 跨字节、CRLF、多行 data、注释、done；错误/中断拒绝残缺工具参数。
- 流式连接总超时、事件超时、响应大小上限、禁止重定向。
- 真正取消：关闭 HttpClient 连接，包括发送准备阶段的模型列表请求。
- 已确认 GitHub 写操作执行时停止禁用，不宣称能够撤销已完成操作；页面退出/切号
  取消可取消模型请求，保留原账号保护。
- 临时流式正文完成后替换正式消息，停止/失败不把半段正文伪装成成功历史。
- 工具过程可展开、限高滚动显示名称/目标/运行/完成/失败/取消。
- Markdown fenced code 单独复制；消息全文复制保留。
- 保守重试：只复用最后相同用户消息，不追加重复气泡；只给模型空工具集，任何
  返回工具调用也拒绝。不自动重放任何尝试过工具的任务，不承诺跨进程 exactly-once。
- 上下文从按 24 条改为字符预算：历史最多 48k 字符、总内容 60k，超限明确错误。
  不删真实历史，不静默裁剪正在进行的工具调用与结果。
- 历史侧栏读独立加密摘要，只打开当前会话正文；旧历史首次生成预览可重试。
- 重命名先加载完整正文，防摘要覆盖；删除同时清除正文和摘要。
- 长会话正文按 40 条渲染窗口加载更早消息，降低初次渲染成本。

## 仍需诚实说明的限制

- 字符预算是保守容量保护，不是模型 tokenizer 精确 Token 计数；未使用不存在的
  模型上下文上限，不伪造输入/输出 Token 用量。
- 单会话加密正文仍按整条读取/写入；UI 渲染窗口不等于磁盘级消息分页。真正消息
  分页涉及旧数据事务迁移，后续需单独设计，不称这项已彻底完成。
- GitHub 请求进行中停止不强制断开写操作；未收到结果可能需要人工核对审计和远端。
- 初次轻量索引升级需要读取旧正文，之后历史列表不再读取所有消息。
- 未做用户真实服务的三协议联网验收（避免消耗用户 API 额度），不是全网所有
  OpenAI 兼容实现的保证；如服务拒绝 stream 会如实报错，不偷偷重复付费请求。
- 尚未真机/大字体/各 Android 输入法验收，不声称全部优化完成或所有设备零 Bug。
