## 不整块覆盖的上游内容及原因

- 上游 AI 架构只提供读取文件工具，且历史/审计改用普通 KV；直接替换会删除本 Fork
  写操作和回滚并降级私有内容存储，因此保留 Fork AI 核心和既有三协议实现。
- 上游 AI 真 SSE 流式尚未适配到 Fork 的工具调用/确认链路。不能宣称这项已复刻；
  后续应单独加兼容流式契约及分块工具调用回归，而非替换现有服务。
- 上游纯文本 AI 回复不替换 Fork Markdown 渲染；这是交互差异，不是必须覆盖的修复。
- 上游清空输入后重试和当前表单模型检测的修复：Fork 本来恢复失败输入且使用 config 快照，
  不采用上游不兼容 DTO；保留现有行为。
- 不替换上游 boot 公钥/fixture/签名流程，不恢复多架构/AAB，不删锁文件与安全回归。
- 历史 README/站点/Release 文案批量重写不覆盖 Fork 文档；来源说明在本文件保留。
- 不创建/覆盖 v8.2.0 tag，不发布 APK，不擅自更换版本号。
