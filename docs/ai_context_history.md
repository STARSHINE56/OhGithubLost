# AI 后续优化：上下文选择与会话命名

基于 073b351 的 improvement/ai-context-history，用户要求暂不构建，
只跑分支 CI，不合 main（避免自动预览构建），不发布 APK，上游不动。

已实现：
- 上下文栏按钮打开仓库/分支选择器，不需要输入 owner/repo 命令。
- 使用登录账号绑定请求，仓库/分支 100 条/页，手动加载下一页；
  搜索只筛选已加载项，不误导为搜索全部。错误可重试，取消不修改会话。
- 保存前重新查询目标分支是否存在，失败保留原上下文；发送/轮询忙时不修改。
- 会话标题支持编辑、留空恢复默认；加密随会话保存，旧数据无 title 自动兼容。
- 历史搜索包含标题，长按/编辑按钮可重命名；不修改消息正文。
- 服务及 UI 回归覆盖账号绑定、标题持久化、旧数据兼容和明确分支选择。
