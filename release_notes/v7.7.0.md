- 移植上游 v8 下载/DNS 修复、动画泄漏治理、分级预加载和悬浮按钮滚动避让。

- 保留 Fork AI 写入确认、回滚、多协议、GitHub 全部已读、Star 管理和贡献统计。

## 安装
- 只支持 arm64-v8a Android 设备。
- 包名和固定 Release 签名保持不变；从同签名版本升级通常可覆盖安装保留数据。
- 旧的一次性 Debug 签名版本不能直接覆盖，卸载前请先备份可导出的数据。
