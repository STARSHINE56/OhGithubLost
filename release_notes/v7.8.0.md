# OGL Fork v7.8.0 · 助手能力与键盘修复

## 新增
- AI 无需先选仓库即可读取账号信息、分页列出可访问仓库（含授权私有/组织仓库）、Star、通知、Gist 和组织。
- 新增仓库/分支/提交/Release/评论/PR 文件/协作者/标签/里程碑/Actions 查询。
- 新增仓库创建更新删除Fork、Star/Watch、分支管理、Release 管理、评论、PR 合并关闭、Actions 重跑取消、通知已读、Gist、协作者及标签里程碑管理。
- 所有写操作保持本地确认、固定账号/目标/参数与审计；删除/合并/权限修改等可能不可逆，确认页明确提示。

## 修复
- 键盘守卫识别真正 EditableText 焦点，不再把真实输入键盘当残留 inset。
- AI 输入页明确避让键盘，手机主壳键盘弹起时隐藏底栏；新增真实嵌套聊天输入回归。

## 边界
- 复用登录 Token 实际授权，不会提升 Token scopes，不将 Token 发送给模型。
- 这是经过实现的 GitHub 白名单，不是所有 GitHub API/scopes：不开放 Secrets、Token 导出、任意请求、强推、企业/账单管理。
- 部分管理操作不支持自动回滚；原有文件/Issue/PR 回滚继续保留。
- 操作权限仍受 Token、仓库角色、组织策略约束；完整工具和参数见 docs/assistant_capabilities.md。
